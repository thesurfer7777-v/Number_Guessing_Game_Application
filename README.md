
# 🎮 Number Guessing Game Application

​A simple, elegant, and interactive number guessing game web application built with HTML, CSS, and JavaScript.


## Features

​🎲 Number Generation - Automatically generates a random number between 1 and 10 for the user to guess.

​⚡ Live Statistics – Track your current attempt count out of a maximum of 3 tries.

​💬 Dynamic Feedback – Receive instant clues (Higher/Lower) and validation messages with responsive UI styling.

​⌨️ Keyboard Support – Press the "Enter" key to submit your guess quickly.

​📱 Responsive Design – Works seamlessly on desktop and mobile devices.

​🎨 Modern UI – Beautiful gradient background with smooth transitions and a centered game card.


## ​Prerequisites
​A modern web browser (Chrome, Firefox, Safari, Edge, etc.)

​No server or installation required
## ​How to Use

**​1.Open the Application**

 ​Simply open gussingGame.html in your web browser.

**2.​Make a Guess**
​    
Type a number between 1 and 10 into the input field. 
​Press Enter or click the "Guess" button.

**​3.Follow the Hints**


​ If your guess is incorrect, the message box will guide you to guess higher or lower.

**4.​Win or Reset**

  ​ Guess correctly within 3 attempts to win, or a new game will automatically start if you run out of tries.
